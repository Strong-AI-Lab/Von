# user_question_prompt_for_relation

**parent_path**: `Thing/Relation`

**Description**: A relation that links a Vontology type to a `#V#prompt_for_llm`. This prompt is used to formulate a natural language question to the user to elicit a value for a specific relation. For example, for the relation `#V#has_occupation`, the prompt might be "What is the occupation of [Instance Name]?".
