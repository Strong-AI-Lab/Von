# understand_user_response_for_relation

**parent_path**: `Thing/Relation`

**Description**: A relation that links a Vontology type to a `#V#prompt_for_llm`. This prompt is used to parse a user's free-text answer and extract a candidate value for a specific relation. For example, if the user responds "She is a software engineer", this prompt would help the LLM extract "software engineer" as the value for the `#V#has_occupation` relation.
