# suggested_relations_for_type

**parent_path**: `Thing/Relation`

**Description**: A meta-relation that links a Vontology type to a set of recommended binary predicates that are suggested for instances of that type. For example, the type `#V#Person` might have suggested relations like `#V#has_occupation` and `#V#has_birthplace`. This allows the system to proactively identify missing information for a given concept instance.
