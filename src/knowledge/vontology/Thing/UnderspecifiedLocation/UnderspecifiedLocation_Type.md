# UnderspecifiedLocation

**Source Concept**: http://sw.opencyc.org/concept/Mx4rvhT1EZwpEbGdrcN5Y29ycA
**SubConcept Of**: Thing

**Description**: The collection of locations, tangible or otherwise, which are typically conceptualized by human beings for purposes of common-sense reasoning as locations. This collection thus includes tangible Places such as <a href="http://sw.opencyc.org/concept/Mx4rvVj07JwpEbGdrcN5Y29ycA" class="cyc_term">Ireland_TheIsland</a>, as well as metaphoric locations. For instance, many states-of-being are conceptualized as abstract locations, such as Trouble ('he saw trouble ahead'), Depression ('she fell into a ...'), <a href="http://sw.opencyc.org/concept/Mx4rvVi1AJwpEbGdrcN5Y29ycA" class="cyc_term">Happiness</a> ('they found bliss together').
