# AIWorkflow

**SubConcept Of**: PropositionalInformationThing

**Description**: An AIWorkflow defines a structured process for an AI Agent (like Von Neumarkt) to execute a specific task. It acts as a machine-interpretable plan, orchestrating multiple steps which may include generating targeted `PromptForLLM` instances, calling functions (e.g., for Vontology queries, data processing, or external API interactions), evaluating conditions, and managing the overall task flow based on intermediate results. Unlike a single, static prompt, an AIWorkflow provides a detailed, potentially dynamic blueprint for achieving more complex goals, enabling systematic and repeatable agent behavior within the Von Neumarkt environment.
