💡 Help & Tips

Vontology Operations:

  • Import adds new concepts without overwriting existing ones
  • Export creates a complete backup of the ontology structure (DISABLED)

Concept Operations:

  • Update mode: Updates existing concepts by name+concept_id, creates new if not found
  • Create new mode: Always creates new concepts, appends suffix if name conflicts
  • Skip mode: Only imports concepts that don't already exist
  • Use preview mode to validate imports before committing changes
  • Export filters help create targeted backups for specific concept types
